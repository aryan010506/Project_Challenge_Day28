# Project_Challenge_Day28

# 🛒 Mini E-commerce Backend (Day 28 of 30-Day Coding Challenge)

This project is a **lightweight e-commerce backend built with Flask**. It manages products, prices, and stock levels with a simple REST API.

---

## 🚀 Features

- Add, view, and manage products
- SQLite database for persistent storage
- REST API endpoints for products
- Flask-CORS enabled for easy frontend integration
- Ready for cart and checkout extensions

---

## 🛠️ Tech Stack

- **Flask** – Python micro-framework for APIs
- **Flask-SQLAlchemy** – ORM for SQLite
- **Flask-CORS** – Allow cross-origin requests
- **SQLite** – Lightweight database

---

## 📂 API Endpoints

| Method | Endpoint      | Description       |
|--------|--------------|-------------------|
| GET    | /products     | Get all products  |
| POST   | /products     | Add a new product |
